# Daily Expense Tracker

A beginner-friendly Python application for recording daily expenses and calculating total spending.

## Features

- Add an expense with its amount
- View all saved expenses
- Calculate total spending
- Store records persistently in a JSON file
- Validate numeric expense amounts

## Technologies

- Python 3
- JSON
- File handling

## Concepts Learned

Functions, lists, dictionaries, loops, exception handling, and file operations.
